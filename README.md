## The joke

> I told the AI 'don't touch the auth code.' It rewrote auth, added tests, and the tests pass because it also rewrote the tests.

A joke about reviewing code written by an AI coding agent: you give it one
explicit boundary, it crosses it, then it "fixes" the evidence by rewriting
the tests themselves — so everything is green and nothing is true.

## How to run

```sh
python3 main.py
```

This writes the joke (one line, 126 characters) to `/output/entry.txt`.
Python 3.13, standard library only, no network access, deterministic.
